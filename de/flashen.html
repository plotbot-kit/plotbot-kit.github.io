Firmware aufspielen

Auf dieser Seite spielen Sie die Firmware des PlotBot auf sein ESP32-Board, direkt aus dem Browser. Sie müssen nichts installieren. Danach steuern Sie den PlotBot mit dem Handy, und spätere Updates spielen Sie über seine Handyseite auf.

Firmware-Version 0.30.1

Das brauchen Sie

  • Einen Computer mit Chrome oder Edge. Damit ist der Weg getestet. Safari kann nicht mit dem Board sprechen.
  • Ein USB-Datenkabel. Manche Kabel laden nur und übertragen keine Daten. Erkennt der Computer das Board nicht, liegt es oft am Kabel.
  • Unter Windows eventuell den Treiber für den USB-Chip CP2102. Meist installiert Windows ihn selbst. Erscheint das Board nicht in der Liste, laden Sie den „CP210x USB to UART Bridge VCP Driver“ bei Silicon Labs herunter.

So geht es

  1. Stecken Sie das ESP32-Board mit dem USB-Kabel an den Computer.
  2. Klicken Sie unten auf „Firmware aufspielen“. Der Browser zeigt eine Liste. Wählen Sie den Eintrag mit „CP210x“ oder „USB to UART“ und klicken Sie auf „Verbinden“.
  3. Klicken Sie auf „Install PlotBot“. Das Fenster ist auf Englisch.
  4. Es fragt, ob Sie das Gerät löschen wollen („Erase device“). Beim ersten Mal dürfen Sie den Haken setzen. Spielen Sie die Firmware später noch einmal auf, lassen Sie ihn weg, sonst ist die Kalibrierung weg. Dann klicken Sie auf „Next“.
  5. Bestätigen Sie mit „Install“.
  6. Warten Sie, bis „Installation complete!“ erscheint. Das dauert etwa eine Minute. Danach startet der PlotBot neu und öffnet sein eigenes WLAN.
Dieser Browser kann nicht mit dem Board sprechen. Öffnen Sie die Seite am Computer in Chrome oder Edge. Der Browser erlaubt die Verbindung hier nicht. Öffnen Sie die Seite über https://plotbot-kit.github.io/.

Die Schaltfläche erscheint nur, wenn JavaScript eingeschaltet ist. Die Firmware geht vom Browser direkt über das Kabel ans Board; dabei verlassen keine Daten Ihren Computer.

Wenn es nicht klappt

  • Bricht die Verbindung ab, halten Sie die Taste BOOT am Board gedrückt, während Sie auf „Install“ klicken. Lassen Sie los, sobald der Fortschritt läuft.
  • Fehlt das Board in der Liste, prüfen Sie Kabel und Treiber (siehe oben).
  • Sie können die Firmware auch ohne Browser über die Konsole aufspielen. Wie das geht, steht im Buch zum PlotBot-Kit.
